🌸 About the Project

Gakuran Academy 3D Student ID Card Generator adalah proyek web interaktif yang dibuat untuk memberikan identitas visual yang unik bagi pemain dan anggota komunitas Gakuran.

Pengguna dapat membuat kartu identitas bergaya akademi/gaming dengan berbagai elemen seperti:

🪪 Identitas pemain

🎖️ Pangkat atau julukan

🖼️ Foto profil

🌈 Tema warna

✨ Efek hologram 3D

💧 Watermark

🏷️ Stiker yang dapat digeser, diputar, dan diubah ukurannya

🌌 Partikel dan efek atmosfer

🔄 Tampilan kartu 3D yang dapat diputar 360°

📥 Download kartu bagian depan dan belakang sebagai PNG

Note: Proyek ini merupakan proyek komunitas/fan-made untuk lingkungan Gakuran di Roblox dan bukan produk resmi Roblox Corporation.

🚀 Getting Started

Proyek ini merupakan aplikasi web client-side sehingga tidak membutuhkan database atau backend untuk fitur utamanya.

1. Clone Repository

git clone https://github.com/USERNAME/REPOSITORY.git

Masuk ke folder:

cd REPOSITORY

2. Jalankan Project

Cara paling sederhana:

Buka index.html menggunakan browser.

Atau gunakan VS Code + Live Server untuk pengalaman development yang lebih nyaman.

3. Mulai Membuat Kartu

Masukkan nama/alias pemain.

Masukkan Student ID.

Pilih pangkat atau buat julukan sendiri.

Upload foto profil.

Atur warna kartu.

Pilih efek hologram.

Tambahkan watermark.

Tambahkan stiker.

Putar dan periksa kartu dalam tampilan 3D.

Download bagian depan atau belakang kartu.
